Premade library templates.
Drop one .json per template here (a popup export, or {"template": {...}, "data": {...}}).
Optional template meta: title, description, category (a slug from Library > gear), image (file in this folder or a URL).
Reload the Popups Library page to see changes.

Folder-per-template (recommended when a design uses images):
  library-presets/my-template/template.json
  library-presets/my-template/images/hero.png
Use relative paths such as "images/hero.png" inside template.json; they resolve to this folder automatically.
A template .zip downloaded from a Library card (one top-level folder with template.json + images/) can be unzipped straight into library-presets/.
Or drag & drop the .zip onto the Library page to import it into My Templates (images go to the Media Library).
