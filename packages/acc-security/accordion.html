Control what is stored with each submission, protect the form against repeated submissions and tune the page behaviour while the popup is visible.

Technical info

Technical info is the IP-address and the User-Agent. The email option adds it to the {{form-data}} merge tag.

Page

Locks the page scrollbar while this popup is visible.

Personal data key fields

Fields that hold the personal data key, usually the email field. WordPress uses them to find, export and erase a person's submissions (Tools > Export / Erase Personal Data).

Antibot protection
seconds

The same data (and / or the same IP-address) is refused during the delay and the visitor sees the error message.
